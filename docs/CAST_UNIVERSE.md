# 👥 THE CAST — NixSpeechFav character universe (v1)

*Fixed names, fixed voices, fixed faces. The cast IS the channel brand.
Style token for all stickers: `NIXFAV-STYLE` = flat 2D cartoon, thick dark
outlines, warm yellow/orange family palette (nod to the classic yellow-cartoon
story channels), simple bold shapes, big expressive eyes, bust/waist-up front
facing, plain transparent background PNG, 1024×1024.*

> ⚠️ Voice IDs validated against live `edge-tts --list-voices` at build time;
> final narrator/host voices get auditioned by the boss before lock.
